# Git Repository & Update Guide

## Repository Details
- **Repository URL**: `https://github.com/rajsubhajit554-cloud/SW-Bhowmick-Hotel-Restaurant.git`
- **Branch**: `main`

## How to Update GitHub Repository

### Option 1: Automatic Update (Recommended)
Double-click on `update_git.bat` file in this directory.
1. It will show current file status.
2. Type a commit message (or press `Enter` to use default).
3. It will automatically run `git add`, `git commit`, and `git push origin main`.

### Option 2: Manual Update (Terminal / Command Prompt)
Run the following commands in the project folder:
```bash
git add .
git commit -m "Your update message"
git push origin main
```
